# データ置き場
ここにはサーバー起動時に読み込まれてステートに格納されるデータ群を置いています。
編集の便を考えてエクセルブック形式で保存しています。

各シートの先頭行にはアイテムのキー、以降の行にはそれらに対する値を記述します。
シートは最終的にベクタとしてパースされ、それらを束ねる大キーとしてシート名が付与されたマップがデータとして格納されます。

また、以下のキーは特殊なものとして扱われます。

## sub-table
現在のデータ行の中に、異なるシートのデータを組み込みます。
ここに入力された文字列はサブテーブルのキーとなり、値として文字列と一致するシートから作られるベクタがアサインされます。

## redirect-from/to
`redirect-from`に入力された文字列をキーとし、`redirect-to`に入力された文字列と一致するシートから作られるベクタを値とします。
sub-tableとの違いは、`redirect-to`に入力した文字列（リダイレクト先のシート名）がデータ格納時に消滅することです。

## xxx-json
値をデータ構造として読み込ませたい場合に使用します。
カラムの名前に`-json`接尾辞を付加すると、値として入力された文字列はjsonとしてパースされます。
キー末尾の`-json`接尾辞はデータとして格納される際に削除されます。
